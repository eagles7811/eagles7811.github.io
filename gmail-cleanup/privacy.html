gmail-cleanup Privacy Policy

gmail-cleanup is a personal tool used only by its owner on their own Google account.

  • Data accessed: Gmail messages, labels, and filter settings of the owner's account, via the Gmail API scopes gmail.modify and gmail.settings.basic.
  • Use: only to organize the owner's own mailbox (labels, read status, archive, filters, and downloading the owner's own attachments to the owner's computer).
  • Sharing: no data is sold, shared with, or transferred to any third party.
  • Storage: OAuth tokens are stored only on the owner's computer. No mail content is stored on any server operated by this tool.
  • Revocation: access can be revoked at any time at https://myaccount.google.com/permissions.
